# Eventify

## Featured Events Page
A responsive single-page web application built as part of a Web Development Internship case study.  
The page displays a list of featured local events in a clean, modern, and mobile-friendly layout.

## Features

- Responsive navigation bar with links to Home, Events, and Contact
- Hero section with a clear call-to-action
- Featured Events section displaying event cards
- Dynamic rendering of events using JavaScript (dummy JSON data)
- Search functionality to filter events by name
- Fully responsive design for mobile, tablet, and desktop screens
- Clean and modern UI using pure CSS

## Tech Stack

- **HTML5** – Page structure
- **CSS3** – Styling and responsive layout
- **Vanilla JavaScript** – Dynamic content rendering and search functionality

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Right-click `index.html` and open it in any modern web browser (Chrome, Edge, Firefox).
